# VidSage 脉络

**看视频，也理清思路。**

把字幕、笔记与 AI 分析放在视频旁边，随时回到原画面核对。

[English](README.en.md) · [上手指南](docs/GETTING_STARTED.zh-CN.md) · [隐私与授权](docs/PRIVACY.md)

## 为什么做 VidSage

我最初做它，是因为自己在看金融学和一些专业课程时，经常遇到这样的时刻：视频已经往下讲了，我还在想上一个概念到底是什么意思。

有了 AI，我可以把难懂的部分拆开，换个说法问一遍，再回到视频里核对。但网页、插件、笔记之间来回切换，总会打断思路。我想要一个自己用着舒服的桌面工具，让视频、字幕、提问和笔记待在一起。无论是本地保存的课，还是 B站、YouTube 上支持的视频，都能边看边想，把知识慢慢变成自己的理解。

这就是我做 VidSage 的起点。也希望它能让你的学习过程轻松一点。

## 从观看到理解

- **字幕跟着视频走。** 使用已有字幕、导入字幕，或用随包轻量模型在本机生成；支持时间跳转、字幕编辑与翻译。
- **分析保留来源。** 围绕字幕进行分析和问答，查看时间位置，再回到原视频判断。
- **留下自己的理解。** 保存笔记与分析资料，供之后继续阅读和检索。
- **服务由你选择。** 配置 API、ChatGPT 云授权或支持的本机服务；媒体账号可跳过，本地播放不依赖 AI 账号。

首次打开保持清爽首页，右上角用四个可跳过的步骤帮助准备服务和字幕。设置收敛为 AI 服务、媒体账号、字幕、播放器四类。

## 安装与使用

完整安装包包含播放器、核心、本地字幕运行库和 base 模型，无需开发环境。公开发布后，下载与校验信息统一放在 GitHub Releases。

1. 安装并打开 VidSage；可跟随引导，也可先播放视频。
2. 打开本地媒体，或输入支持的 B站 / YouTube 地址。
3. 获取字幕，再按需使用 AI 学习、问答和笔记。

[阅读完整操作指南 →](docs/GETTING_STARTED.zh-CN.md)

更新使用完整 Setup，先关闭播放器，再安装到原目录。Windows 标准卸载入口已提供；升级和卸载默认保留资料。关于页提供版本检查入口，公开更新渠道尚未启用。

## 隐私与反馈

本地字幕在本机运行。云端分析、问答或翻译会在授权后向所选服务发送字幕和必要上下文；ChatGPT 登录不是本地模型。密钥与令牌受 Windows 当前用户加密机制保护，必要账号信息在本机保存。

运行记录保存在本机，目前没有自动上传接收端。通过「关于 → 报告问题」检查并导出 ZIP，再决定是否分享。图片及元数据不自动脱敏。随机安装编号只关联主动分享的报告，不读取硬件序列号。
