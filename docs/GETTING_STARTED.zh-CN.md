# 开始使用 VidSage

[English](GETTING_STARTED.en.md) · [隐私与授权](PRIVACY.md)

VidSage 把视频、字幕、分析和笔记放在同一个工作区。先打开视频，再按需要准备字幕和 AI 服务。

## 安装、更新与卸载

当前候选为 **0.1.77 · Windows 11 x64**。公开安装包尚未放行；只从项目最终公布的 GitHub Releases 获取文件，并核对该版本的 SHA256。当前候选未签名，不代表发布者身份已通过系统认证。

完整安装包包含播放器、自包含核心、本地字幕运行库和 base 轻量模型。无需安装 Node.js 或 .NET SDK；为安装与临时解压预留至少 4 GB。可选大模型需要额外空间。

运行 Setup，选择安装目录并完成安装。首次打开时两侧栏收起；未配置 AI 时，右上角会出现轻量上手邀请。可以开始，也可以稍后再说。

更新时先关闭播放器，再运行新版完整 Setup，选择原安装目录。资料与账号保存在独立数据目录，旧程序版本保留。应用运行时安装器会提示先关闭，不会强行结束任务。「关于 → 更新与安装」提供版本检查入口；公开渠道确定前显示准备中。目前尚无自动下载、后台热替换或静默安装。

卸载使用 Windows「设置 → 应用 → 已安装的应用 → VidSage → 卸载」。卸载默认保留字幕、笔记、模型、账号资料和诊断记录；重新安装可以继续使用。开发预览目录的资料不会自动搬入正式安装目录。

## 四步上手

1. **连接 AI。** 在「AI 服务」选择 API 服务或 ChatGPT 订阅授权。API 需要你自己的服务地址、密钥与模型。ChatGPT 登录会在浏览器打开官方授权流程；它连接云端服务，不是本地 GPT 模型。播放视频和本地生成字幕不需要 AI 账号。
2. **按需登录媒体账号。** B站账号可用于读取该账号有权访问的媒体及字幕；可以直接跳过。YouTube 当前支持公开视频，登录不是前置步骤。
3. **准备字幕。** 优先使用已有字幕；也可导入本地字幕。没有字幕时，在字幕任务中选择随包 base 模型并点击开始。更大的模型由你主动选择和下载，可查看进度及取消。在指引中点击“使用此模型”可设为默认；检查或准备成功、开始字幕任务时也会记住所选模型。
4. **开始理解视频。** 打开本地媒体或网络地址，获取字幕，再打开「AI 学习」。分析、问答与翻译使用所选服务；首次向某服务发送内容前会请求确认，授权按服务保存。

每一步都可前进、返回或跳过。随时通过「关于 → 上手指引」重新打开。引导不会自动开始模型下载、转写或付费推理。

## 看视频，也理清思路

- 点击字幕或结果里的时间，回到对应画面核对原话。
- 根据当前字幕提问，将重要内容整理为笔记和资料。
- 正在播放且确认没有可用字幕时，右下角可能提示使用本地字幕。提示可关闭，倒计时结束后自行消失；悬停或键盘聚焦会暂停计时。“生成字幕”只打开任务面板，需再次确认才开始。
- 识别、翻译和分析都可能出错。尤其是专有名词、数字、多人重叠讲话，请回看原视频；重要决定应结合可靠来源和适当专业意见。

## 设置在哪里

| 分类 | 内容 |
|---|---|
| AI 服务 | 授权、API、服务与模型选择、连接检查 |
| 媒体账号 | 可选的平台登录与会话管理 |
| 字幕 | 字幕显示、翻译、本地识别模型、模型存储 |
| 播放器 | 播放习惯、界面、图标、本地记录 |

「关于 → 支持作者」提供微信支付和支付宝二维码，默认收起。金额自愿，不影响功能。

## 遇到问题

打开「关于 → 报告问题」，填写发生时间和现象，可选择最多三张图片，预览文本与附件清单后导出 ZIP 到本机。程序打不开时，从开始菜单打开「VidSage 反馈与诊断」。目前没有自动接收端，导出不等于已经发送给作者。

应用保留有限的本机运行记录。报告中的本机安装编号由随机数生成，用于关联你主动分享的报告，不读取硬件序列号；可以复制或重置。重置不会删除资料，也不会改变已分享的报告。

分享前检查文字、图片及图片元数据，移除密钥、账号、私人媒体或敏感内容。详细数据流见[隐私说明](PRIVACY.md)。
