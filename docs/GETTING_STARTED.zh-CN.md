# 开始使用 VidSage

[English](GETTING_STARTED.en.md) · [隐私说明](PRIVACY.md)

VidSage 将视频、字幕、AI 分析和笔记放在一起。你可以先播放视频，再按需要配置字幕和 AI 服务。

界面支持简体中文和 English。在「设置 → 播放器 → 界面语言」选择语言或跟随系统，切换不会改变字幕、报告和笔记正文。

## 安装

VidSage 适用于 **Windows 11 x64**。从[官方下载页](https://github.com/Elviszhuoyu/VidSage-Releases/releases)选择所需版本，下载完整安装包 `VidSage-版本-win11-x64-Setup.exe`。普通用户只需这个 EXE；`Content-Setup` 和 `.vsp` 是应用更新附件，不是首次安装入口，其他源码附件供有需要的开发者使用。

安装包已包含播放器、本地字幕运行库和 base 模型，无需另装开发环境。安装和解压至少预留 6 GB 空间。

1. 双击下载的 Setup EXE。
2. 按安装向导选择程序目录，阅读许可并完成安装。默认目录可以直接使用，也可以选择其他磁盘中的专用目录。
3. 启动 VidSage，跟随上手指引或选择跳过。

当前测试安装包未签名，Windows 可能显示“未知发布者”或“Windows 已保护你的电脑”。确认文件来自上方官方下载页后，若系统提供“更多信息 → 仍要运行”，可选择继续。若提示恶意软件、没有继续选项或无法确认来源，请停止并反馈，不要关闭系统防护。

### 可选：核对文件摘要

需要确认下载文件与发布页一致时，可以在 PowerShell 中运行以下命令，将路径替换为文件位置：

```powershell
Get-FileHash -LiteralPath "安装包完整路径" -Algorithm SHA256
```

结果应与该版本发布页 SHA256SUMS.txt 中的安装包摘要完全一致；若不一致，请停止安装并重新检查下载来源。

摘要用于核对下载文件，不能代替数字签名或安全检测。

## 首次使用

打开软件后，可以跟随右上角的上手指引，也可以跳过。之后可从「关于 → 上手指引」重新打开。

1. 打开本地视频或受支持的网络地址。播放本地视频无需 AI 账号。
2. 使用视频已有字幕，或导入字幕文件。没有字幕时，在字幕任务中选择可直接使用的模型并开始生成。设置 → 字幕会分别显示模型文件和运行环境；“已下载”不等于“可直接使用”。
3. 需要分析、问答或翻译时，在「AI 服务」配置自己的 API、连接 ChatGPT，或选择受支持的本机服务。云服务可能单独计费；发送内容前，软件会请求授权，并记住所选服务的授权状态。
4. 打开「AI 学习」，根据字幕分析和提问。长字幕会分段处理，显示已返回段数、正在分析的范围和已用时间；全部核对后保存报告。等待时仍可播放，取消或失败会保留已有报告。点击字幕或结果中的时间可以跳回视频，重要内容可保存为笔记。

全片提问可以继续讨论当前报告和最近问答中的例子。视频解释保留字幕引用，概念补充与假设示例单独标识；AI 报告不会变成视频原文证据。报告及问答上下文会随问题发送给你选用的服务，详情见[隐私说明](PRIVACY.md)。

Gemini 的可用模型和免费额度由你的项目决定。本机测试可选 Lite 进行分析和问答，不需要为此启用付费。不同模型的逐句翻译质量会有差异；日语等跨语序字幕可能重排内容，请保留原轨并核对译文，不能只凭“生成完成”判断语义正确。

B站登录可用于访问该账号有权观看的媒体和字幕，可以按需设置。YouTube 当前支持公开视频。

本地生成字幕无需额外 AI 账号。更大的模型需要你主动选择并下载，详情见[系统要求与模型选择](HARDWARE.zh-CN.md)。

应用图标默认深色，可在设置 → 播放器切换浅色。两侧分隔条支持拖动和键盘左右箭头调整宽度。

## 报告图片与免费导出

报告中的「更多 → 导出报告长图」只在本机排版已有内容，不调用 AI，不需要生图账号。导出时显示状态，保存成功后提示完成；取消保存可直接重试。超过长图高度上限时，改用 Markdown 导出。

需要 AI 配图时，在「设置 → AI 服务 → 生图」选择已有官方 API 账号或添加密钥。设置一次后，从报告点击「AI 生图」；选中文字时使用选段，清空选区恢复整份报告。Gemini 生图需要付费 API 层级；ChatGPT 订阅接入和 DeepSeek API 暂不支持生图。可用模型、额度和费用以服务商账号为准。

生图状态会显示在报告旁，可以取消等待。成功后在图片浮窗查看，支持滚轮缩放、拖动、适配、全屏、最小化、复制、另存和定位目录。更多选项可调整版式、查看旧版图片；重新生成保留历史版本，清缓存保留已生成图片。生图取消或超时不保证服务端停止处理，也不保证不计费，软件不会自动重试。

## 设置

| 分类 | 可调整的内容 |
|---|---|
| AI 服务 | API、登录授权、服务与模型、连接检查 |
| 媒体账号 | 平台登录与会话管理 |
| 字幕 | 字幕显示、翻译和本地识别模型 |
| 播放器 | 界面语言、播放习惯、界面、图标和本地记录 |
| 存储 | 模型与缓存位置、磁盘占用和缓存清理 |

默认模型与缓存位置可以直接使用。需要更改时，打开「设置 → 存储」选择新位置；软件复制并核对文件后启用新目录，原目录保留。清理缓存前会显示可清理项目；字幕、笔记和账号资料不在缓存清理范围内。

「关于 → 支持作者」提供自愿打赏入口，不影响软件功能。

## 常用操作

在资源管理器中可通过「打开方式 → VidSage」打开媒体。需要设为默认播放器时，前往 Windows「设置 → 应用 → 默认应用」选择；安装不会强制改变现有默认应用。无痕播放期间从外部打开的文件进入本次无痕会话。

播放支持的 B站视频时，可从画质入口选择当前视频和账号实际可用的清晰度；切换失败时保留原可播画质。右键视频选择「播放统计」，可查看分辨率、编码、帧率、丢帧、缓存时长和硬件解码；复制统计不含媒体标题、文件路径或播放地址。

在「AI 学习」打开「评论区」，读取当前 B站视频的公开顶层样本。读取不会调用模型；确认服务和样本后才总结或发送问题。引用可回到样本原评论，样本观点不代表全部观众，也不作为视频事实。样本及回答只在本次会话保留。

通过「AI 服务 → 用量与费用」或学习区快捷入口查看请求、Token 和费用估算。订阅、本机与 API 分开显示；服务未返回用量时显示不可用。默认以人民币CNY显示。适用模型使用官方参考单价，也可手动保存单价和汇率；未知请求不计入金额，价格随时段变化时显示区间。模型用量可按Token、请求或费用排序，估算不能替代服务商账单。无痕用量退出后清理。

## 无痕播放

在左侧播放列表标题旁点击帽子与眼镜图标。界面切换为石墨灰，产品名右侧显示「无痕播放」和退出入口；普通队列保留，本次从空的临时队列开始。可以打开本地媒体或在线链接，使用字幕、分析、问答和临时笔记。

切换准备期间保留原画面并显示进度状态；窗口就绪后以柔和过渡进入，退出时反向恢复。系统启用减少动态效果时使用短淡化。切换画面仅在内存中使用，不保存为截图文件。

退出时清理本次临时数据并恢复普通队列。首版字幕和结果不提供导出；平台账号和 ChatGPT 登录与普通模式隔离，云端 AI 需重新确认本次处理授权。具体留存与清理边界见[隐私说明](PRIVACY.md)。

## 更新与卸载

正常启动自动检查一次更新，也可从顶部提示或「关于」手动检查。有兼容内容更新时，软件核对本机可复用文件，只下载缺失内容，无需逐版升级；完整安装包仍作为备用入口。进度显示实际下载量与复用量。校验完成后，由你确认退出、安装和重新打开；正在运行的任务或未保存设置需先处理。旧版若不能完成更新，请从官方下载页手动下载并运行当前可用的新版 Setup。

卸载入口为 Windows「设置 → 应用 → 已安装的应用 → VidSage」。更新默认保留资料。自0.1.91起，交互式卸载提供三个独立选项：缓存与诊断、默认目录的下载模型、个人资料与登录信息，默认全部不勾选。删除个人资料需再次确认，之后无法恢复。自定义或迁移到其它位置的模型/缓存、开发预览资料及外部导出文件始终保留；静默卸载也始终保留用户数据。

## 问题反馈

在「关于 → 报告问题」填写情况，检查内容后导出诊断 ZIP。程序打不开时，可从开始菜单打开「VidSage 反馈与诊断」。

诊断包保存在本机，需要你主动提交才会发送给作者。分享前请检查文字和图片，删除账号、密钥、私人路径等敏感信息。操作步骤见[反馈指南](FEEDBACK.zh-CN.md)。

字幕和 AI 结果可能出错，尤其是专有名词与数字，请回看原视频核对。


完整安装包保留 base 字幕模型、CPU 离线处理和 NVIDIA 加速组件。内容复用减少后续更新下载，不缩减首次安装包。条款变化时需在安装向导阅读并确认。
