# 开始使用 VidSage

[English](GETTING_STARTED.en.md) · [隐私说明](PRIVACY.md)

VidSage 将视频、字幕、AI 分析和笔记放在一起。你可以先播放视频，再按需要配置字幕和 AI 服务。

## 安装

当前测试版为 **0.1.80，适用于 Windows 11 x64**。从[官方下载页](https://github.com/Elviszhuoyu/VidSage-Releases/releases/tag/v0.1.80)下载 `VidSage-0.1.80-win11-x64-Setup.exe`。普通用户只需这个 EXE，其他源码附件供有需要的开发者使用。

安装包已包含播放器、本地字幕运行库和 base 模型，无需另装开发环境。安装和解压至少预留 6 GB 空间。

首版安装包未签名，Windows 可能显示“未知发布者”或“Windows 已保护你的电脑”。安装前请核对来源和文件摘要：

1. 在 PowerShell 中运行以下命令，将路径替换为你下载的文件位置：

   ```powershell
   Get-FileHash -LiteralPath "安装包完整路径" -Algorithm SHA256
   ```

2. 确认结果与下方 SHA256 完全一致。如果不同，请停止安装并重新检查下载来源。
3. 核对后，若 Windows 提供“更多信息 → 仍要运行”，可选择继续。若提示恶意软件、没有继续选项或无法确认来源，请停止并反馈，不要关闭系统防护。
4. 运行安装包，选择目录，按提示完成安装。

0.1.80 安装包的 SHA256：

`aa9d787103af26e4771dc499dbea0e17b485e61a8911440e64a5fc5e55b2a549`

摘要用于检查文件是否与发布页一致，不能代替数字签名或安全检测。其他版本请使用对应发布页的校验值。

## 首次使用

打开软件后，可以跟随右上角的上手指引，也可以跳过。之后可从「关于 → 上手指引」重新打开。

1. 打开本地视频或受支持的网络地址。播放本地视频无需 AI 账号。
2. 使用视频已有字幕，或导入字幕文件。没有字幕时，在字幕任务中选择 base 模型并开始生成。
3. 需要分析、问答或翻译时，在「AI 服务」配置自己的 API、连接 ChatGPT，或选择受支持的本机服务。云服务可能单独计费；发送内容前，软件会请求授权，并记住所选服务的授权状态。
4. 打开「AI 学习」，根据字幕分析和提问。点击字幕或结果中的时间可以跳回视频，重要内容可保存为笔记。

B站登录可用于访问该账号有权观看的媒体和字幕，可以按需设置。YouTube 当前支持公开视频。

本地生成字幕无需额外 AI 账号。更大的模型需要你主动选择并下载，详情见[系统要求与模型选择](HARDWARE.zh-CN.md)。

## 设置

| 分类 | 可调整的内容 |
|---|---|
| AI 服务 | API、登录授权、服务与模型、连接检查 |
| 媒体账号 | 平台登录与会话管理 |
| 字幕 | 字幕显示、翻译、本地识别模型和存储位置 |
| 播放器 | 播放习惯、界面、图标和本地记录 |

「关于 → 支持作者」提供自愿打赏入口，不影响软件功能。

## 更新与卸载

在「关于 → 更新与安装」检查新版本，打开下载页获取新版安装包。关闭 VidSage 后运行安装包，选择原安装目录。软件不会自动下载或安装更新。

卸载入口为 Windows「设置 → 应用 → 已安装的应用 → VidSage」。更新和卸载默认保留字幕、笔记、模型、账号资料和诊断记录；重新安装后可继续使用原资料。

## 问题反馈

在「关于 → 报告问题」填写情况，检查内容后导出诊断 ZIP。程序打不开时，可从开始菜单打开「VidSage 反馈与诊断」。

诊断包保存在本机，需要你主动提交才会发送给作者。分享前请检查文字和图片，删除账号、密钥、私人路径等敏感信息。操作步骤见[反馈指南](FEEDBACK.zh-CN.md)。

字幕和 AI 结果可能出错，尤其是专有名词与数字，请回看原视频核对。
