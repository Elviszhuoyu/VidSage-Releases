# Reporting a problem

[简体中文](FEEDBACK.zh-CN.md) · [Open an issue](https://github.com/Elviszhuoyu/VidSage-Releases/issues/new/choose)

A repeatable description helps more than “it does not work.” You do not need coding knowledge or a video upload to report a problem.

## Include these details

1. The app version and approximate time of the problem.
2. Where you started and the actions you took.
3. What you expected and what actually happened.
4. Whether it happens every time and after restarting.

For captions, add the model, video duration, and source language. For playback, add the file format or platform. For startup, say whether you used a desktop shortcut, Start menu, or the application folder. Windows version, CPU, RAM, and GPU can help; hardware serial numbers are unnecessary.

## Export a diagnostic package

1. Open **关于 → 报告问题 (About → Report a problem)** and describe the issue and steps.
2. Optionally select images, then choose **预览诊断包 (Preview diagnostic package)**.
3. Review the text and attachment list. Image content and metadata are not automatically redacted. Remove names, accounts, keys, private paths, and private media.
4. Confirm your review and select **导出 ZIP 到本机 (Export ZIP locally)**.
5. Open the [GitHub issue form](https://github.com/Elviszhuoyu/VidSage-Releases/issues/new/choose), describe the problem, and attach a ZIP or screenshot only if it is suitable for public sharing.

**Exporting does not send the report. GitHub Issues are public.** If material cannot be shared publicly, start with a description containing no sensitive information and wait for the author to confirm a suitable contact method. Do not upload credentials, account files, private videos, or full transcripts.

## If the player will not open

Use **VidSage 反馈与诊断 (VidSage Feedback and Diagnostics)** in the Start menu. This starts without the player core or speech recognition service. For installation failures, describe the installer message. Installer logs may contain local paths and are not automatically included in the diagnostic ZIP.

Limited runtime records stay on your computer. A random installation identifier relates reports you choose to share and can be reset. Read the [privacy statement](PRIVACY.md).

## Suggestions and recognition errors

Explain what you are trying to accomplish, where the current flow gets in the way, and the interaction you would prefer. For recognition errors, a short recording you have permission to share and the correct words may help. Check it for private or restricted content first. Report interface behavior and recognition accuracy separately.
