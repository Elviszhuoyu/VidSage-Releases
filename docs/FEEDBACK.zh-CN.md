# 反馈问题

[English](FEEDBACK.en.md) · [提交问题](https://github.com/Elviszhuoyu/VidSage-Releases/issues/new/choose)

欢迎反馈使用中的问题和建议。请尽量写清操作步骤，无需提供代码或上传完整视频。

## 问题描述

1. 你用的版本，以及问题出现的大致时间。
2. 从哪个入口开始，依次点了什么。
3. 原本希望发生什么，实际发生了什么。
4. 是否每次都出现；重启后是否还会出现。

描述示例：“打开本地 MP4，选择 base 生成字幕后，进度一直停在音频准备。等待两分钟、重启软件后仍然如此。”

字幕问题再补模型、视频时长及源语言；播放问题补文件格式或平台名称；启动问题补是桌面快捷方式、开始菜单还是程序目录入口。CPU、内存、显卡和 Windows 版本有助于定位，硬件序列号不需要提供。

## 从软件导出诊断包

1. 打开「关于 → 报告问题」，填写问题描述和复现步骤。
2. 按需选择图片，点击「预览诊断包」。
3. 展开检查文本及附件清单。图片内容和元数据不会自动脱敏，请遮住姓名、账号、密钥、本机私人路径和私人媒体。
4. 勾选确认后，点击「导出 ZIP 到本机」。
5. 打开[GitHub 问题页](https://github.com/Elviszhuoyu/VidSage-Releases/issues/new/choose)，填写描述；只有确认内容适合公开时，才主动附上 ZIP 或截图并提交。

**导出不等于已经发送。GitHub Issues 对所有人公开。** 如果材料不能公开，先只提交不含敏感内容的描述，等作者确认合适的沟通方式；不要上传原始凭据、账号文件、私人视频或完整字幕。

## 播放器打不开

从开始菜单打开「VidSage 反馈与诊断」，检查并导出诊断包。安装失败时，可说明安装器显示的提示；安装日志可能含本地路径，不会自动加入诊断包，分享前也需要检查。

本机运行记录有限保存，不会自动上传。随机安装编号用于关联你自愿分享的报告，可以在软件中重置。详情见[隐私说明](PRIVACY.md)。

## 功能建议和识别错误

说明你希望完成的事情、当前卡在哪一步，以及期望的操作方式。识别有误时，可提供一小段有权分享的片段和正确文字；先确认无私人或受限内容。模型可能漏词、误识别数字和专有名词，反馈界面问题与识别质量时请分别说明。
