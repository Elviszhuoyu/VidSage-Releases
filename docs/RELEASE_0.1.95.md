# VidSage 0.1.95 · 看视频的事，继续就好

这次把一轮观看中的细节补齐：临时打开的视频有独立的空间，想深入的内容可以继续问，AI 偶尔用不了也不必停下来。

## 这版更新了什么

- **无痕播放重新整理。** 入口仍在播放列表旁，进入后在产品名旁显示状态。临时队列、登录环境、字幕、分析和笔记与日常资料分开，退出后清理本次数据。过渡效果遵循减少动态效果设置。
- **分析更完整，引用更好回看。** 优化长文复盘、财经复盘、知识拆解和行动清单；正文解释与字幕依据分开，章节仍可跳转。围绕视频或报告追问时，保留原文时间，AI 补充会单独标明。
- **失败后还有路可走。** 分析、翻译和问答提供“继续看原文”“稍后重试”“手动换服务”。设置和已有资料保留，失败的问题可放回输入框。不会自动重试，也不会自动换到收费服务。
- **安装与卸载更顺手。** 修复卸载后仅有 Python 缓存残留导致原位置不能重装的问题。卸载可分别选择清理缓存、默认目录模型和个人资料，默认保留。
- **按需要准备模型。** 标准包带 Whisper base；千问运行环境和模型单独选择准备，不把大模型一同塞进安装包。
- 更新首页介绍、完整功能清单和当前版本无痕截图。

## 如果使用 Gemini API 免费层

免费层能用哪些模型、请求频率、每日额度和地区限制由 Google 决定。开发测试中碰到过：

1. 服务返回 503，暂时无法生成。
2. 长内容返回不完整，需要缩小范围或稍后再试。
3. 请求成功，但内容、分句或引用仍需要回到原文核对。

连接测试通过不代表每次生成都能完成。其他 API 及 ChatGPT 订阅同样受各自额度、网络与模型限制，不保证始终稳定。遇到失败，可以继续看原文、记笔记，稍后再自己决定是否重试或换服务。软件不会自动转到收费服务。

## 下载和更新

Windows 11 x64，处理器需支持 x86-64-v3（含 AVX2）。普通使用只下载 **VidSage-0.1.95-win11-x64-Setup.exe**；SOURCE_INDEX 和源码附件是第三方组件配套材料。建议为安装及临时解压预留至少 6 GB。安装包未签名，升级保留资料和模型。

无痕播放不提供网络匿名或磁盘取证不可恢复保证。视频与 AI 平台仍按各自规则处理数据。语音识别、翻译和分析可能出错，请核对重要内容。

这是公开测试版；本机检查不能覆盖所有电脑、显卡和系统缩放环境。欢迎附上复现步骤反馈问题。
