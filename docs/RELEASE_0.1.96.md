# VidSage 0.1.96 · 把软件里的更新入口补完整

这版集中修复应用内更新。此前部分网络环境下，GitHub匿名接口额度用完，软件只提示“检查网络”，即使新版已发布也找不到安装包。这是更新链路的缺口，本版补上备用方式和实际升级验证。

## 这次怎么更新

- 正常启动后会自动检查一次，发现新版在顶部显示入口；也可进入“关于 → 检查更新”。不会自动下载大安装包或中断播放。
- 更新检查优先读取官方更新清单，不占用GitHub匿名API额度。清单不可用时才作一次备用检查；限流和网络失败会说明原因，并保留下载页入口。
- 点击下载安装包，可查看进度、取消及稍后续传。完整校验通过后，再由你确认“退出并更新”。
- 与当前安装已接受的条款一致时，确认后自动安装并重新打开；条款变化时显示向导供你阅读确认。字幕、笔记、设置和模型保留。
- 更新请求使用系统网络配置，并逐项检查安装包来源、大小和SHA256；校验失败不会安装。修复附件跳转的兼容问题。
- 修复安装助手可能提前退出的问题；只有助手确认就绪后，播放器才会关闭。助手启动失败时仍可继续使用。
- 后续发布会自动刷新官方更新清单，应用无需写死下个版本的下载地址。

## 旧版用户先做一次升级

**如果0.1.95及更早版本仍提示无法检查更新，请先手动运行这次的完整安装包一次。** 旧版本本身没有新的备用检查逻辑，无法通过发布说明远程补上。安装0.1.96后，后续版本即可从软件里检查、下载并确认更新，不必每次去GitHub找包。

下载 **VidSage-0.1.96-win11-x64-Setup.exe** 即可，升级保留资料。软件仍需联网访问官方更新源和附件，无法在网络完全不可达时完成下载。标准包约908MiB，Windows11 x64；未签名。

本版保留0.1.95的无痕播放、分析与引用、失败保底和安装/卸载修复。它仍是公开测试版，不代表所有电脑或网络条件都已验收。
